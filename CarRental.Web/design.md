# Design System — SMARTDRIVE (Automotive & Luxury Rentals)

A locked design system for SmartDrive extracted from reference demo `123websitedemo.com/?id=9362` (Automotive Dealership & Luxury Rental).

## Provenance
Extracted via `hallmark study` from reference `http://123websitedemo.com/?id=9362` (Automotive Dealership & Rental Template).

## Genre
`classic-premium-automotive` (Crimson Red + Dark Charcoal + Light Grey Showroom Surface)

## Macrostructure Family
- **Home / Main Showroom**: Top Utility Bar + Dark Header (Active Crimson Red Tab) + Hero Slider with Quick Action Ribbon + 4-Column Feature Bar + Welcome & Inventory Search Diptych + Featured Fleet Section + 5-Column Services & Operations + Dark Statistics Bar + 3-Column Dark Charcoal Footer.

## Theme & Tokens
- `--color-paper`: `#ffffff`
- `--color-paper-subtle`: `#f5f5f7` (Light Showroom Grey)
- `--color-paper-dark`: `#1a1a1a` (Dark Charcoal)
- `--color-paper-black`: `#0f0f11` (Deep Automotive Black)
- `--color-ink`: `#1a1a1a`
- `--color-ink-muted`: `#555555`
- `--color-accent`: `#d32f2f` (Crimson Automotive Red)
- `--color-accent-hover`: `#b71c1c`
- `--color-rule`: `#e5e5e7`
- `--color-rule-dark`: `#2d2d30`

## Typography
- Display / Headings: `Space Grotesk`, `Barlow Semi Condensed`, sans-serif (Bold, uppercase tracking)
- Body: `Plus Jakarta Sans`, `Inter`, sans-serif
- Numbers & Telemetry: `JetBrains Mono` with `tabular-nums`
